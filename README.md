# OCE Connections

This repository is the successor to [OpenClaw Connections](https://github.com/raw-labs/openclaw-connections). It retains the Composio adapter and connector catalog. OCE will own saved connections and agent grants.

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm inspect:package
```

See [RELEASING.md](RELEASING.md) for distribution and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for provenance.
